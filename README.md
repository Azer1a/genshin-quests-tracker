# Genshin Quest Tracker

Веб-приложение для удобного отслеживания прогресса прохождения квестов в игре **Genshin Impact**. Проект помогает не забыть, какие задания уже выполнены, а какие еще предстоит пройти.

## Текущий функционал
- **4 категории квестов:** Архонта, Легенды, Мировые и Встречи.
- **Удобная навигация:** 
  - Мировые квесты разбиты по регионам.
  - Квесты Архонта — по томам и главам.
  - Встречи — по персонажам (с отметкой каждой концовки).
- **Локальное сохранение:** Прогресс сохраняется в `LocalStorage` вашего браузера — можно закрывать вкладку и возвращаться к списку позже.
- **Визуальный стиль:** Светлая тема, вдохновленная интерфейсом Паймон.

## Использованные технологии
- **HTML5** (семантическая верстка).
- **CSS3** (БЭМ-методология, CSS-переменные, Flexbox, Grid).
- **JavaScript (ES6+)**:
  - Работа с DOM (рендеринг списков, динамическое создание элементов).
  - Работа с `LocalStorage`.

## Как запустить локально
1. Склонируйте репозиторий.
2. Откройте проект в VS Code.
3. Запустите файл `index.html` через расширение **Live Server** (или любой другой локальный сервер). 
*Важно:* просто открыть `index.html` двойным кликом не получится, так как проект использует ES-модули (браузер заблокирует их из-за CORS).
